# cancer_detection_tilburg
Cancer Detection – Deep Learning

This project focuses on classifying eight types of skin lesions using deep learning.

We developed a baseline CNN model, experimented with different hyperparameters to improve performance, and explored transfer learning using pretrained models such as DenseNet121, VGG16, and ResNet50.

The project was completed as a group assignment for the Deep Learning course at Tilburg University.

Technologies: Python, CNNs, Deep Learning, Transfer Learning, DenseNet121.
